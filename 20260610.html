# PubMedダイジェスト ハイライト 2026/06/10

今週はCGM由来指標の臨床応用を問い直す研究が並んだ。まず ★Diabetes Care にて Ajjan ら（Leeds）が、HbA1cと平均血糖の乖離を個人の赤血球特性で補正する個別化HbA1c（pA1C）を提案した。1型・2型257例・4人種の26週前向き研究で、全体の33%（黒人では41%）が0.5%以上の乖離を示し、pA1C導入で乖離は全体14%（58%減）、黒人12%（71%減）まで縮小した。CGMとHbA1cの不一致を人種差まで踏み込んで定量した点で、先生のCGM研究に直結する。一方で同時期、★🇯🇵JCEM では増田ら（大阪大学）が日本人1型153例のCGM指標を機械学習でクラスター分類し、4類型のうち血糖変動が最大のCluster4が多発神経障害・baPWV上昇・心血管リスクで最悪と示した。CGMプロファイルそのものが合併症リスクの層別化に使えるという、データ駆動型の新しい視点である。

デバイス領域では運動と自動インスリン投与（AID）の組み合わせが二報。Diabetes Technol Ther の Zaharieva ら（Stanford）は、AIDの一時目標値設定が小児1型の運動を延長（110対78分）させつつ低血糖なしにTITR>50%達成を増やす（54対37%）と報告。だが同誌の AIDing Exercise 試験（Steno）では、運動前対策を講じても高強度・中強度いずれの運動でも低血糖が残り、現行AIDが運動時の安全性をなお保証しきれないと釘を刺した。技術の進歩と限界が同じ週に並んだ格好だ。

日本発の実臨床データとして🇯🇵Diabetol Int で高木ら（東京女子医大）が、1型へのSAP/CSII導入後HbA1cが1年で約0.8%低下し3年間維持されることを示した。治療領域ではDiabetes Care のFINE-ONE探索的解析が、1型＋CKDでフィネレノンがHbA1cや罹病期間によらずアルブミン尿を25%低減（p=0.0001）と報告し、1型腎症への新たな選択肢を補強した。

今週の共通テーマは「CGM指標をHbA1cの代替・補完としてどう臨床に落とし込むか」。日本人研究は大阪大（JCEM）・東京女子医大（Diabetol Int）の2件と充実していた。
