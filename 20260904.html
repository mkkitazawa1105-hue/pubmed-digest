# 今週のハイライト（2026-09-04）

今週は「CGMを渡すだけでは足りない」という主題が複数の論文から別々の角度で立ち上がった。

まず★J Korean Acad Nurs にて Yang ら（全北大学校）が、2型糖尿病102名を「CGM単独」「CGM＋個別化生活コーチング」「標準教育」の3群に分けたRCTを報告した。3か月時点のHbA1cは対照群比で CGM単独 -0.78ポイント、コーチング併用 -1.12ポイント。さらに6か月時点では、高血糖の時間（TAR180）がコーチング併用群で対照群より 7.85ポイント、CGM単独群より 8.28ポイント低かった。CGMという道具の上に人の介在を重ねた分だけ、結果が積み上がる。★JMIR Mhealth Uhealth の Lalani ら（ハーバード大）はこれを別方向から裏づける。前糖尿病者向けAIアプリのRCT事後解析で、利用日数が多い層は複合アウトカム達成のオッズが 2.59倍（95% CI 1.11-6.01）、5%以上の減量が 3.31倍だった。使われなければ効かない、という当たり前が数値で出た。

同時期に★Front Endocrinol からインド4施設のRCT（コーチ架電＋食事写真アプリ、90日）が出たが、扱いには注意がいる。HbA1c 1.46% 低下と派手だが、本文では脱落が介入群3名に対し対照群28名と極端に偏っていた。効果量よりこの非対称性が読みどころである。

CGMを「何で測るか」という指標論も動いた。★Diabetol Int で大野（慈恵医大）が TITR（70-140 mg/dL）を総括している。通常のTIRが天井に張り付く正常高値～境界型の層で差を出せる指標だが、頻回注射のT1Dでは TITR が高いほど TBR も伸びうるとの警告も併記される。指標を狭めれば低血糖と隣り合う。★Front Endocrinol の Yu ら（南京鼓楼病院）はさらに踏み込み、食後高血糖を「面積」として定義（PPHA）し、新規診断2型糖尿病297名で6か月後の尿アルブミン変化と結びつけた（5単位増ごとに ΔlnUACR +0.08, 95% CI 0.05-0.12）。CGM指標を血糖の記述で終わらせず臓器障害の予測に使う流れだ。

一方でCGM＋AIには冷や水も浴びせられた。★PLOS Digit Health の Lu ら（ダートマス大）が血糖予測の深層学習8手法を136万件のCGMデータで再実装したところ、技術的再現性はあっても別コホートへの一般化は乏しく、血糖が不安定な人ほど誤差が大きい。IEEE TBME の Calzavara らはさらに具体的で、RMSEが同等でも危険な行動を推奨する割合はモデルにより最大 64.3%、生理制約を課した PhyNet のみ 0% だった。精度指標だけで臨床に入れてはいけない。

小児領域では Ann Pediatr Endocrinol Metab（韓国、216名）が、診断1か月以内のCGM開始群で5年後HbA1c中央値 6.8%、未使用群 7.3%（かつ年 +0.27% の上昇軌跡）と報告した。導入の早さが5年後に効く。T1D予防では Diabetes Care の TrialNet 解析が、単一自己抗体陽性者を負荷後血糖＋C-peptideで2年進行率50%超と5年10%未満に切り分けた。

日本発は3件。うち評価Aは 🇯🇵Diabetol Int の坂根ら（京都医療センター）で、1型糖尿病121名のリポハイパートロフィーがポンプでも注射でも約6割と、投与方法によらず高頻度だった。

今週の共通テーマは「CGMとデジタル介入は、測る範囲・使われ方・検証の作法まで設計して初めて成果になる」。日本人研究は3件（うちA評価1件）だった。
